# 校园闲置物品交易平台 (Campus Fleamarket)

这是一个基于 **[前端框架，如 Vue/React]** + **[后端框架，如 Spring Boot/Node.js]** 开发的校园二手交易平台。旨在为学生提供一个便捷、安全的闲置物品流转渠道。

## 🛠 技术栈
*   **前端**：Vue.js / React, HTML5, CSS3, Axios
*   **后端**：Java Spring Boot / Node.js
*   **数据库**：MySQL
*   **其他**：[比如：阿里云 OSS 图片存储、JWT 鉴权、WebSocket 实时通讯（如果有的话）]

## ✨ 核心功能
*   **用户模块**：注册登录、个人信息管理、实名认证（学生认证）。
*   **商品模块**：闲置物品发布、分类浏览、关键字搜索、商品详情展示。
*   **交易模块**：留言/私信沟通、收藏/点赞、交易状态流转。
*   **管理模块**：后台违规商品下架、用户管理。

## 📂 项目结构
*   `/frontend` - 前端源码
*   `/backend` - 后端源码

## 🚀 本地运行指南
1. 导入数据库文件（若有）。
2. 修改后端配置文件中的数据库连接信息。
3. 前端运行 `npm install` 和 `npm run serve`。
4. 后端启动主程序。

*(注：本项目为团队协作开发/个人全栈实践项目)*
